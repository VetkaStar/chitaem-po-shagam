# Разработка версии 3

Сначала прочитайте docs/ARCHITECTURE.md и выберите относящийся к задаче модуль. Оригиналы reading-app и reading-app-lab не менять. Исправление чтения было сделано и проверено до разделения интерфейса (6de6554).

При изменениях распознавания прочитайте docs/READING.md. Не показывайте ребёнку произвольную расшифровку. Не засчитывайте частичную гипотезу или один звук как правильный ответ. После изменения поведения обновите документацию и тесты. Выполняйте npm test, npm run typecheck, npm run build. Проверка на синтетической записи не заменяет проверку детской речи.
