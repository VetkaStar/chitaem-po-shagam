# Читаем по шагам

Бесплатный тренажёр чтения by Vetka_Star. Для всех детей, с особым вниманием к детям с аутизмом, СДВГ и ЗПР.

Рабочая версия исходников: **reading-app-v4**. [Приложение](https://vetkastar.github.io/chitaem-po-shagam/).

## Разработка

Node.js >=22.13.0. В отдельной установке: `pnpm install --frozen-lockfile`, затем `pnpm dev`.
Локальная v4 использует ссылку на существующие зависимости: не обновлять пакеты через неё.

- `pnpm test` — учебная логика и сценарии.
- `pnpm run typecheck` — типы.
- `pnpm run build:pages` — GitHub Pages.
- `pnpm run build` — Vinext.

Push в main автоматически запускает тесты, проверку типов, сборку и публикацию.

Есть буквы, слоги, слова, картинки, предложения, рассказы и стихи. Тексты поддерживают чтение, письмо и вопросы. Материал ограничивается выбранной темой; наполнение продолжается.

Прогресс и настройки сохраняются в этом браузере. Облачной синхронизации пока нет. Ключи хранения сохранены в V4. Модель Vosk лежит в public/speech, речь обрабатывается на устройстве; нужен HTTPS или localhost. Для случаев ошибки распознавания доступна проверка взрослым.
