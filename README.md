## В этой версии

- Медленное чтение по частям: подтверждённое начало слова сохраняется между паузами, подсвечивается; приложение сообщает, что слышит звук, и ждёт продолжения.

- Один запуск микрофона на занятие, автоматическое продолжение после следующей карточки и отдыха. Реальный спектр звука, пауза распознавания во время озвучки.
- Посторонний распознанный текст не выводится. Известный неверный учебный ответ сравнивается с заданием; сомнительное распознавание не считается ошибкой. Помощь усиливается после повторных затруднений.
- «Ловлю»: три медленно движущиеся карточки, ввод любой видимой карточки + Enter, зелёная отметка и замена. Движение можно отключить.
- Перемешивание наборов при новом занятии, без одинаковых соседних карточек. В словах отдельный начальный словарь из восьми слов, расширяющийся с материалом.
- Картинки: известные синонимы и уменьшительные названия признаются подходящими; ребёнку предлагают потренировать целевое написание. Для похожих объектов есть мягкое уточнение и контекстная картинка. Неизвестные ответы получают подсказку без красной ошибки. Это словарь вариантов, а не универсальное понимание любого ответа.
- Отдых: четыре разминки, пузырьки, пары, музыкальные цветы, мелодия и авторский стишок с движениями. Мелодия инструментальная; стишок озвучивается речью. Нет проигрыша и обязательного таймера.
- Сведения об учебнике оставлены в разделе взрослого; убраны из детского задания.

## Следующие разделы — план, пока не реализованы

1. **Предложения:** чтение по словам, сборка фразы из перемешанных слов, выбор подходящей картинки. Начинать с 2–3 слов. Проверять понимание отдельно от распознавания речи.
2. **Рассказы:** маленькая сцена, 2–4 предложения, вопросы «кто / что сделал / где», последовательность событий. Несколько вариантов текста и вопросов, без заучивания порядка.
3. **Стихи:** короткие авторские четверостишия, прослушивание строк, ритм, продолжение с подсказкой. Повторение по желанию, без требования читать на скорость.

## Запуск

Node.js >=22.13, pnpm. `pnpm dev` — локально, `pnpm build` — сборка. Для микрофона нужен HTTPS или localhost. Vosk и модель лежат в `public/speech`; звук обрабатывается на устройстве. Первый запуск скачивает около 46 МБ, затем модель кэшируется браузером.

## Ограничения

Автоматическое распознавание отдельных слогов и детской речи может ошибаться; ручная проверка взрослым остаётся доступной. Озвучка зависит от русских голосов устройства. Перечень слов и вариантов названия нужно расширять по наблюдениям на реальных занятиях. Новые разделы выше требуют отдельной разработки.
