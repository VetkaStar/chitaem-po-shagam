## Связи

ReadingApp вызывает useLesson один раз. Компоненты получают типизированный Pick<LessonModel> только с нужными полями. Они не создают второй микрофон и не ведут отдельный счёт. Бизнес-правила находятся в lib; useLesson связывает их с состоянием интерфейса. Модель распознавания лежит в public/speech; её контрольные суммы проверяет загрузчик.

## Изоляция версий

Работать только в reading-app-v4. Предыдущая v3 сохранена без изменений. Ключ прогресса: reading-steps-v3. У исходных версий другие репозитории, адреса и ключи. Локальный node_modules — ссылка на установленные зависимости lab: не редактировать содержимое зависимостей и не обновлять их через эту ссылку. Для изменения зависимостей сначала нужна отдельная установка в v4.

## Правила изменений

1. Выбрать модуль, изменить только его контракт и необходимые места вызова.
2. Для изменения поведения обновить tests/regression.mjs и соответствующий раздел docs/READING.md.
3. Выполнить npm test, npm run typecheck и npm run build.
4. Для микрофона дополнительно проверить реальный звук, паузу, подсказку, следующий экран и остановку. Текстовые тесты не доказывают качество распознавания детской речи.
5. Добавить запись в CHANGELOG. Не переносить исправления в рабочие старые версии без отдельного указания.

Темы: features/lesson/TopicNavigation.tsx — детская навигация; lib/topics.ts — порядок тем; use-lesson.ts/changeTopic — сброс занятия при переходе.

Свободный ответ принимает только перечисленные синонимы; это не универсальная семантическая модель. Новые допустимые ответы добавлять в synonyms в lib/session.ts. Части предмета по-прежнему получают признание наблюдения и вопрос про целый предмет.

## Единая навигация
AppPortal теперь владеет общей шапкой, левым меню и диалогами для всех экранов. ReadingApp передаёт только содержимое упражнения. В LessonSidebar семь разделов; активный раздел определяется экраном портала. LessonHeader получает onHome/onCabinet: логотип возвращает домой без перезагрузки, кабинет соседствует с настройками. Переход go закрывает диалоги и останавливает микрофон; paused больше не означает «мы на другом экране».

visibilitychange останавливает микрофон при скрытии вкладки, но не открывает отдых. use-rest-schedule считает время только после ввода/речевой активности и прекращает счёт после 30 секунд без активности. Открытая нетронутая вкладка не запускает таймер. После возвращения в занятие нужна новая активность. Напоминание по времени по-прежнему ждёт границы задания.

Цветовосприятие: lib/vision.ts, features/lesson/VisionSettings.tsx и vision.css. Настройка colorVision; режим передаётся также в портальные диалоги и игры. Обоснование, источники и проверенные ограничения — COLOR-VISION.md.

Подсказки к неверным ответам на картинки: lib/picture-retry.ts. Сначала смысловые варианты/детали, затем близкое написание, затем ступени повторной попытки. Первый посторонний ответ не раскрывает слово. В окошках маркировка начинается со второй такой попытки; ошибки написания получают точечную помощь сразу.

Размеры пузырьков: lib/rest-games.ts/bubbleGrid задаёт сетку; features/lesson/bubble-layout.css фиксирует поле, размеры кружков зависят от ячейки через container units. Стиль подключается после прежних игровых стилей.

Общая геометрия отдыха: features/lesson/rest-layout.css задаёт постоянную рамку для меню, разминки, музыки, пузырьков и пар. RestHub разделяет прокручиваемую rest-activity и неподвижную кнопку возврата. pairGrid задаёт сетку 2–8 пар внутри поля высотой 320px; карточки уменьшаются при увеличении сложности. На коротком экране прокручивается только центральная область.

components/completion-celebration.tsx и .css — общее поздравление пар и пузырьков, портал над диалогом, таймер 2000 мс с очисткой при смене задания и размонтировании. Постоянный доступный текст результата остаётся в игре; декоративный слой скрыт от скринридера и не перехватывает ввод.

Библиотека: TextLibrary выбирает материал, features/library/TextExercise.tsx координирует три режима и вопрос после чтения. use-text-microphone.ts владеет отдельным потоком только на экране библиотеки (основное занятие там выключено); lib/text-practice.ts проверяет последовательные подтверждённые части и написанный текст. Настройки библиотеки хранятся отдельно в reading-text-options-v1. Общие звёзды и журнал обновляются через awardReadingText с указанием режима. tests/text-practice-flow.mjs проверяет реальный хук распознавания и переходы TextExercise.

Общая тема — settings.unit. lib/topic-material.ts проверяет изученные буквы; lib/session.ts фильтрует словарь, lib/topic-texts.ts отбирает читаемые тексты и варианты ответа с приоритетом недавно открытых тем. content/topic-texts.ts содержит авторские короткие заготовки. TextLibrary ведёт последовательность текстов внутри темы, не возвращает к каталогу после ответа. LetterDisplay.tsx отвечает за звук в скобках, название буквы и варианты Б/б/Б б; letterCase сохраняется в общих настройках.

Навигатор чтения: lib/reading-guide.ts создаёт части строки с исходными позициями; ReadingGuide/ReadingGuideControls — общие элементы слов и текстов. readingFocus (line/word/syllable) и readingHighlight сохраняются в settings. TextExercise хранит покрытие подтверждённых букв и прочитанных строк; выбор поздней части не засчитывает пропущенную. В словах selectReadingPart запускает отдельную попытку без награды за неполное слово.


Общая панель темы: components/topic-bar.tsx и topic-bar.css. TopicNavigation адаптирует её для первых разделов, TextLibrary использует тот же компонент для текстов. Порядок кнопок: предыдущая, список тем, следующая. TextLibrary использует lesson/lesson-top, TextExercise — общую рамку exercise и mode-list; стили текста остаются в text-practice.css.


Автопереход: components/auto-advance.tsx (жизненный цикл таймера), auto-advance-settings.tsx (общая настройка), auto-advance.css. Используется ExerciseCard и TextExercise, настройки доступны в занятии и ParentSettings. lessonLength и continueLesson в useLesson ограничивают повторы слов текущей темы.


TaskInstruction — общий компонент инструкции с озвучкой. use-text-microphone сохраняет подтверждённый префикс фразы. TextExercise владеет автоматическим/ручным ведением строк, полный текст остаётся видимым. TextLibrary считает выполненные тексты перед общей похвалой. Каталог адаптивных изображений: content/illustration-sources.ts; предзагрузка: components/use-illustration-preload.ts.
