## Связи

ReadingApp вызывает useLesson один раз. Компоненты получают типизированный Pick<LessonModel> только с нужными полями. Они не создают второй микрофон и не ведут отдельный счёт. Бизнес-правила находятся в lib; useLesson связывает их с состоянием интерфейса. Модель распознавания лежит в public/speech; её контрольные суммы проверяет загрузчик.

## Изоляция версий

Работать только в reading-app-v3. Ключ прогресса: reading-steps-v3. У исходных версий другие репозитории, адреса и ключи. Локальный node_modules — ссылка на установленные зависимости lab: не редактировать содержимое зависимостей и не обновлять их через эту ссылку. Для изменения зависимостей сначала нужна отдельная установка в v3.

## Правила изменений

1. Выбрать модуль, изменить только его контракт и необходимые места вызова.
2. Для изменения поведения обновить tests/regression.mjs и соответствующий раздел docs/READING.md.
3. Выполнить npm test, npm run typecheck и npm run build.
4. Для микрофона дополнительно проверить реальный звук, паузу, подсказку, следующий экран и остановку. Текстовые тесты не доказывают качество распознавания детской речи.
5. Добавить запись в CHANGELOG. Не переносить исправления в рабочие старые версии без отдельного указания.

Темы: features/lesson/TopicNavigation.tsx — детская навигация; lib/topics.ts — порядок тем; use-lesson.ts/changeTopic — сброс занятия при переходе.

## Старт, кабинет и новые тексты
- features/portal/AppPortal.tsx — главное меню и экраны; перед выходом из занятия останавливает микрофон и озвучку.
- Welcome.tsx / profile.ts — имя, возраст, стартовый раздел; локальный ключ reading-profile-v1, проверка сохранённого профиля.
- Cabinet.tsx — звёзды и анонс кастомизации. Никаких покупок и облачного аккаунта пока нет.
- About.tsx / content/links.ts — автор, поддержка, контакты и Google Forms.
- content/reading-library.ts — авторские предложения, рассказы и стихи с вопросами.
- features/library/TextLibrary.tsx — чтение по строкам, озвучка, понимание; отдельный экран, без оценки произношения длинного текста.
- content/word-bridges.ts / features/lesson/WordBridge.tsx — сборка слов в разделе слогов после каждого второго принятого ответа.
- lib/learning.ts — 13 тем. curriculumVersion=2 мигрирует прежний полный алфавит на последний индекс, сохраняет прогресс.
- lib/breaks.ts — частота разминок и приоритет конца занятия.
