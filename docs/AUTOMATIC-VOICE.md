# Временная автоматическая озвучка — 18.09.2026

В «Для взрослого → Автоматическая озвучка» доступны системный голос и **Piper — Ирина, на устройстве**. Сохраняется `settings.narrator: system | piper-irina`, неизвестные значения восстанавливаются как `system`. Самопроизвольного скачивания при открытии сайта нет: Piper загружается при первом нажатии динамика/«Послушать голос» после выбора. Исходный вариант по умолчанию сохранён, качество голоса выбирается прослушиванием.

В родительской панели можно ввести до 500 символов для сравнения, увидеть загрузку/подготовку, прослушать и остановить речь. Пример не сохраняется в профиль. Для Piper используется один женский голос, поэтому выбор пола системного голоса в этом режиме недоступен. «Медленная озвучка» меняет скорость воспроизведения до 0.8 с сохранением высоты тона средствами браузера.

## Исполнение

- `lib/piper.worker.ts`: `@mintplex-labs/piper-tts-web@1.0.5`, `ru_RU-irina-medium`, ONNX Runtime Web WASM; текст обрабатывается локально. Веса ≈63 МБ плюс runtime/фонемизатор. Модель/конфигурация загружаются из `diffusionstudio/piper-voices` на Hugging Face и сохраняются библиотекой в OPFS, если браузер разрешает. Фонемизатор WASM/data — версия `@diffusionstudio/piper-wasm@1.0.0` на jsDelivr; ORT поставляется со сборкой. Никакого API синтеза и отправки текста нет. Полный офлайн сайта не добавлен.
- `lib/piper-client.ts`: один worker, отмена текущего вычисления завершает его, тайм-аут 180 с, освобождение после минуты простоя. Обработанная модель переиспользуется между воспроизведениями. Ошибка не подменяется молча системным голосом.
- `lib/piper-speech.ts`: общий управляемый проигрыватель, предварительная активация аудио по нажатию, отмена, блокировка запоздалого воспроизведения, освобождение blob URL. Аудиозапись не сохраняется в пользовательский профиль.
- Обычные занятия/библиотека используют `lesson-voice-actions.ts`, вход 0.8.1 — `entry08/media.ts`. Отключение микрофона во время образца, фиксация помощи до озвучки и проверка устаревших попыток сохранены. Закрытие настроек/скрытие вкладки/смена материала останавливают озвучку.
- Для Piper eSpeak используется только внутри браузерного WASM-фонемизатора для преобразования текста; синтез звука делает нейросеть. Нативная программа eSpeak, вызвавшая ранее сбой Windows, не устанавливалась и не запускалась.

## Источники и границы

[Браузерная библиотека](https://github.com/Mintplex-Labs/piper-tts-web), [исходный голос](https://huggingface.co/rhasspy/piper-voices/tree/main/ru/ru_RU/irina/medium), [карточка используемой копии](https://huggingface.co/diffusionstudio/piper-voices/blob/main/ru/ru_RU/irina/medium/MODEL_CARD). Карточка указывает датасет RHVoice и `License: Unknown`; разрешение коммерческого распространения голоса этой интеграцией не установлено. Сейчас выполнено локальное подключение для проверки, без публикации.

Не утверждаем, что Piper правильно озвучивает все изолированные согласные, слоги и ударения. Прежняя защита звуков букв сохранена: название согласной не выдаётся за изолированный звук. Качественные заранее подготовленные записи остаются отдельной работой. Реальные iOS/Android и старые устройства ещё не проверены; отсутствие задержки генерации не обещается.

## Проверки

- `tests/piper-speech.mjs`, подключён к `test`: отмена до/во время генерации, запрет позднего воспроизведения, медленная речь с `preservesPitch`, освобождение ресурсов.
- `tests/free-audio-flow.mjs`: Piper, как и прежняя озвучка, ждёт сохранения помощи; устаревшая попытка не начинает воспроизведение.
- `node tests/piper-browser.mjs` после сборки: реальный Edge/WASM, скачивание, генерация и проигрывание русской фразы, сохранение выбора, отмена, отсутствие переполнения при 390/820/1920. Требует Playwright (`PLAYWRIGHT_PACKAGE`) и сеть для первой загрузки. Пример и снимки только в `.local/piper-tests/`; это техническая проверка, не экспертная оценка произношения.
