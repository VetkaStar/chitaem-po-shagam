# Добровольный первый вход — этап 4

14.09.2026. Учебные программы подключены к локальной сборке AppPortal. Публичный сайт не обновлялся.

## Пользовательский путь

В существующем каталоге появился вход «Учебные программы». Он добровольный: «Настроить позже» сохраняет отсрочку и сразу возвращает к семи тренажёрам. Анкета, демонстрации и проверки не запускаются от этой кнопки. Возврат в раздел восстанавливает сохранённое состояние.

Для выбравших настройку доступны анкета, проверка управления круг/квадрат, входные задания и отчёт. Неизвестные ответы остаются неизвестными; возраст, интересы и самоотчёт не подтверждают чтение. Демонстрации открываются по желанию. Явно выбранные настройки звука и движения применяются после сохранения; автоматическая озвучка инструкции работает только при разрешённом аудио.

Две ошибки управления возвращают к настройкам доступа. Размер и другие настройки существующего интерфейса доступны через «Для взрослого». Успех управления не является учебным навыком.

Без помощника предлагаются конкретные задания предварительной практики. Они используют общие исполнители и историю показов, но не двигают официальный курс и не создают входных подтверждений.

## Контракты и сохранение

| Модуль | Ответственность |
| --- | --- |
| CurriculumPortal | Ленивая загрузка комплекта и открытие IndexedDB; ошибка, повтор и независимый выход |
| OnboardingRoot | Последовательная UI-очередь, восстановление экрана и маршрутизация форм |
| QuestionnaireForm + questionnaire-*.tsx | Сохранение анкеты и небольшие группы полей |
| AccessSetup | UI_ACCESS с доступными кнопками и клавиатурой |
| EntryWorkspace | Пробы, промежуточные ответы, подтверждение и пауза |
| EntryReport + entry-report-*.tsx/ts | Самоотчёт, наблюдения, входные подтверждения и следующий доступный шаг |
| entry-state / entry-actions / entry-execution | Переходы и сырые ответы в черновике единственного контроллера |
| entry-commands | Команды контроллера; собственного состояния или хранилища не имеет |
| lib/curriculum/entry-planner.ts | Типизированная граница неизменённого entry_planner.mjs |
| lib/progress/validation-entry.ts | Проверка checkpoint, metadata, наблюдений и происхождения экземпляров |

CurriculumController остаётся единственным владельцем учебного состояния, очереди записи и commit. Схема ProgressState v2 дополнена необязательным onboarding.entry и отдельным источником entry; старые состояния без новых полей принимаются. Исходные ключи профиля, настроек и прогресса тренажёров не перезаписываются при создании учебного профиля.

До показа пробы сохраняются checkpointId, группа, точный instance/item/hash, доступность и сведения о свежести/помощи до предъявления. Затем записываются экземпляр и экспозиции. В UI нет ключей ответа или тестовых готовых результатов.

Частичный passage сохраняет прежние instanceId, порядок вариантов, стадию чтения и ответы. Наблюдение появляется только после завершённой попытки; оно заново выводится из сырого ответа исходным evaluateAttempt. Импорт сверяет наблюдение с попыткой и metadata.

Подтверждение взрослого применяется только к текущей серии одной группы: два разных пригодных материала, нужное покрытие и явное наблюдение. Результаты разных групп и прежних повторных проверок не складываются. Итог confirmed_entry не означает mastered, не присваивает буквы и не отмечает уроки пройденными. ASR и произвольная строка вместо ReadingProof не засчитываются.

При resolvePlacement сохраняется profileToPersist во всех возвращающих его ветках, включая остановку/действие ядра. Рекомендованная цель отделена от фактического старта. Незавершённый официальный экран сохраняется; его нельзя затереть новым размещением.

## Паузы, повтор и боковые группы

Бюджет 3/5/7 ограничивает новые учебные экраны. После исчерпания доступны пауза и предварительный отчёт; продолжение в новом подходе сохраняет прежний checkpoint и уже пригодные наблюдения. Два подряд технически непригодных результата ведут к отсрочке и практике, без понижения чтения.

Явное откладывание текущей проверки фиксирует активное задание как skipped и сохраняет отчёт атомарно. Подсказанные в этом подходе материалы исключаются при повторной пробе по правилам источника.

Боковая очередь сохраняет основную цель. Дополнительная группа предлагается только по желанию, при остатке минимум двух экранов и не более одной вставки за подход. Сначала Л/П, затем М/Ш; словесная часть требует decode.cv_cv.

Из отчёта убраны названия будущих эпизодов, содержащие проверочные слова. Точные episodeId остаются в сохранённом решении для сверки, но не раскрываются как учебный материал заранее.
