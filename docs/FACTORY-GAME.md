# Чудо-завод

Самостоятельная браузерная игра в `public/games/factory/`. Открывается по `/games/factory/index.html` при `npm run dev`; статические файлы копируются сборкой в `dist-pages/games/factory/`. Можно перенести весь каталог на любой статический HTTP-сервер. Внешних библиотек, шрифтов и сетевых сервисов нет. Для ES-модулей нужен HTTP-сервер; открытие через `file://` не поддерживается.

## Правила

Нажатие поворачивает деталь на 90 градусов. Нужно соединить старт, станок с шестерёнкой и финиш. После запуска груз проходит по фактически соединённым деталям. При разрыве появляется отметка «!», схему можно исправлять без ограничения попыток. Во время проверки поле заблокировано; сброс, выбор сложности или уровня отменяет текущий запуск. После победы предлагается следующий уровень, после четвёртого — следующая сложность.

- Лёгкая: четыре поля 5 × 5, один маршрут с водой.
- Средняя: четыре поля 6 × 6, длинные конвейеры, лишние детали.
- Сложная: четыре поля 6 × 6, два независимых маршрута с водой и грузом. Для победы нужны оба станка и оба финиша.

Тип материала обозначен и цветом, и формой (круг / ромб, гладкая труба / поперечины ленты). Нет таймера или штрафа за эксперимент. Все уровни доступны сразу.

## Управление и границы

Мышь и касание: нажать на деталь. Клавиатура: Tab, Enter/пробел; стрелки перемещают фокус по доступным деталям в строке/столбце. Интерфейс адаптируется от ширины 320 px; учитывает prefers-reduced-motion. Пройденные уровни сохраняются отдельно в `little-factory-progress-v1`; при недоступном хранилище игра продолжает работать в памяти.

Платформа чтения, выдача наград, таймер отдыха, микрофон, профиль и учебный прогресс не подключены. Каталог — самостоятельная поставка игры; интеграция оставлена следующему разработчику. `model.js` содержит чистые правила, `game.js` — интерфейс и жизненный цикл запуска, `style.css` — стили только самостоятельной страницы.

## Проверки

`node tests/factory.mjs` (также включён в `npm test`) проверяет решаемость всех 12 уровней, разрывы, обязательный станок, разделение материалов, фиксированные клетки, циклы и воспроизводимость сброса.

`node tests/factory-browser.mjs` проверяет реальные нажатия, победу, повтор, переключение во время запуска, сохранение и мобильную геометрию. Использует Playwright из `PLAYWRIGHT_PACKAGE` или установленного пакета и Edge по умолчанию; снимки сохраняются в `.local/factory-browser/`.
