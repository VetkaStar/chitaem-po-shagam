# Первый вход и каталог тренажёров

При создании нового локального профиля после имени, возраста и оформления открывается добровольная настройка учебной программы. Выбранный в знакомстве любимый раздел остаётся стартовым для кнопки «Начать занятие», но сам по себе не запускает упражнение и не задаёт уровень навыков.

«Настроить позже» возвращает каталог без входных проб. Семь прежних разделов сохранены; дополнительно доступны «Собираем слова», «Делим на части», «Находим часть», «Меняем слово», «Читаем и понимаем» и «Выбираем ответ». Они открываются с главной и из бокового меню. Обычный каталог подписан «Тренажёры», а учебная дорожка остаётся отдельной функцией.

Для выбранного локального профиля ключ `reading-first-entry-v1` сохраняется через `browserStorage`: `pending` возвращает после перезагрузки в учебные программы, `deferred` оставляет каталог. Ответы анкеты и точный шаг настройки отдельно сохраняются общим контроллером в изолированной базе профиля. Откладывание не удаляет эти ответы и не означает завершения диагностики.

Переход из программы к другому экрану считается явным выходом к свободной работе; настройку можно продолжить кнопкой «Учебные программы». Редактирование имени и возраста возвращает кабинет, не запускает знакомство и не сбрасывает анкету. Ранее существовавшие профили без нового ключа открывают главную.

Профиль показывается только после успешного `registerCurrentProfile`. При отказе сохранения остаётся форма с сообщением. Выход из кабинета передаётся `logoutProfile`; данные не удаляются.

Проверка: `tests/first-entry-browser.mjs` запускает настоящее приложение в отдельном браузерном профиле. Проверяет создание, перезагрузку приглашения и незавершённой анкеты, откладывание, семь старых и шесть новых разделов, редактирование, сохранение ответов, отказ записи и существующий профиль.
