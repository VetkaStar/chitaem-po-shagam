# GitHub Pages

Для Pages добавлена отдельная статическая точка входа static-entry/main.tsx. Она использует те же модули ReadingApp; копии учебной логики нет.

`pnpm run build:pages` создаёт dist-pages. В сборке относительные пути к ресурсам: приложение работает и в корне, и в каталоге репозитория. Речевые файлы загружаются относительно document.baseURI. На Pages открывать адрес с завершающим `/` (GitHub перенаправляет корень каталога автоматически).

Workflow: .github/workflows/pages.yml. После подключения репозитория выбрать Settings → Pages → Source → GitHub Actions. При push в main выполняются установка по pnpm-lock.yaml, регрессии, проверка типов, статическая сборка и deploy. HTTPS на опубликованном адресе позволяет браузеру запросить микрофон.

Установка зависимостей не выполняет lifecycle-скрипты. Большие файлы модели лежат в public/speech частями и входят в Pages artifact. Голоса, история ребёнка и localStorage в репозиторий не попадают.

## Прогресс

В localStorage под reading-steps-v3 хранятся настройки, число звёзд и последние 300 записей результата. Незаконченная карточка/номер задания не сохраняются. Экспорт CSV находится в настройках взрослого; импорта и облачной синхронизации пока нет.

Данные привязаны к браузеру и origin. При переходе с chatgpt.site на github.io история автоматически не переносится. На другом устройстве будет собственная история. После очистки данных сайта локальное сохранение пропадёт.

Документация GitHub: https://docs.github.com/en/pages/getting-started-with-github-pages/using-custom-workflows-with-github-pages
