# Общие требования к иллюстрациям «Читаем по шагам»

Основной документ для всех пакетов иллюстраций проекта. Сюжеты и перечни изображений задаются в отдельных заданиях; папки, имена, форматы и размеры — здесь. Рабочая папка: `C:\work\app\reading-app`.

Все рабочие материалы и ориентиры находятся внутри этой папки. Внешние папки и архивы для выполнения заданий не требуются. «Исходники» ниже — новые полноразмерные изображения, сдаваемые в `materials/illustrations/incoming/` внутри проекта.

## 1. Куда сдавать новые изображения

Готовые исходники складывать **внутри проекта**, отдельно от файлов сайта:

| Пакет | Папка для сдачи |
| --- | --- |
| Следующий пакет слов, word-23…word-46 | `C:\work\app\reading-app\materials\illustrations\incoming\words-23-46\` |
| Последовательные сцены рассказов | `C:\work\app\reading-app\materials\illustrations\incoming\stories\` |
| Будущие пакеты | `materials/illustrations/incoming/<название-пакета>/` внутри проекта |

Один файл — одно изображение. Не объединять варианты или кадры в коллаж. Сдавать отдельные файлы; ZIP не требуется.

Папка `materials/` исключена из Git и публичной сборки. Новые исходники там нужны для дальнейшего редактирования и повторной оптимизации. После приёмки их сохраняем в `materials/illustrations/approved/<название-пакета>/`; переносит ответственный за интеграцию, после проверки. Не заменять существующие принятые файлы новым вариантом без проверки.

**Копирование в incoming само по себе не добавляет картинку в приложение.** Подключение выполняется после проверки и подготовки размеров для сайта.

## 2. Форматы и разрешения исходников

| Тип | Размер исходника | Соотношение | Формат сдачи |
| --- | --- | --- | --- |
| Предметы, слова и карточки: main, alternate, context | 1024 × 1024 px каждый | 1:1 | PNG или WebP |
| Общая сюжетная иллюстрация | 1600 × 900 px | 16:9 | PNG или WebP |
| Последовательный кадр рассказа | 1600 × 900 px каждый | 16:9 | PNG или WebP |

PNG предпочтителен для исходника без потерь; качественный WebP также принимается. Цветовое пространство — sRGB. Без анимации. Не увеличивать маленький файл искусственно до указанного размера. Не сдавать JPEG, HEIC, PDF, скриншоты или превью вместо исходных изображений.

Для принятого рисованного стиля используется спокойный светлый фон. Прозрачность нужна только если она прямо оговорена в задании конкретного пакета.

## 3. Как называть файлы

Только латинские строчные буквы, цифры и дефис. Без пробелов, кириллицы, суффиксов final/copy и случайных номеров. Расширение соответствует реальному формату. Идентификаторы брать из задания пакета, не назначать заново.

### Предметы и слова — три отдельных варианта

- `main` — основное изображение предмета.
- `alternate` — другое базовое изображение того же понятия.
- `context` — тот же предмет в понятном окружении.

Пример для ВОДЫ из следующего пакета:

```text
word-23-main.png
word-23-alternate.png
word-23-context.png
```

Если сдаётся WebP, заменить только расширение на `.webp`. Для word-24…word-46 действует тот же шаблон. Не сдавать одновременно PNG и WebP одного варианта как две разные картинки.

Уже существующие семейства `picture-NN`, `word-NN`, `scene-NN` сохраняют свои ID. Новые номера не должны пересекаться с каталогом.

### Последовательные кадры рассказов

Номер — порядок события, а не альтернативный ракурс:

```text
story-seed-01.png … story-seed-04.png
story-cat-01.png  … story-cat-03.png
story-boat-01.png … story-boat-03.png
```

Для этих кадров суффиксы main/alternate/context **не нужны**. Точные действия и персонажи перечислены в [задании к рассказам](STORY-ILLUSTRATIONS.md). Нельзя заменять очередное событие альтернативной общей картинкой.

## 4. Единый визуальный стиль

- Ориентир — уже принятые тёплые рисованные изображения в `public/illustrations/reviewed-120/`.
- Спокойные цвета и фон, читаемый главный объект, без лишних мелких деталей.
- Без надписей, букв, логотипов и водяных знаков.
- Предмет целиком, без случайных обрезаний, если задание не требует фрагмента (например, ухо).
- Main и alternate заметно различаются, но однозначно обозначают одно слово. В context окружение не заслоняет главный предмет.
- В рассказе сохраняются внешность и одежда персонажей, предметы и место действия. Меняется событие.
- Иллюстрация соответствует написанному тексту, а не предполагаемому продолжению. Например, в текущем «Ростке» нет финала с цветком.

## 5. Версии для сайта — готовит интегратор

На сайт поступают **статические WebP**, а не полноразмерные исходники. Размер рамки в интерфейсе сохраняется; оптимизируется сам файл. Пропорции сохранять, не растягивать и не обрезать изображение ради размера.

| Тип | Основной файл | Дополнительные файлы |
| --- | --- | --- |
| Квадрат | 320 × 320 px | 640 × 640 px |
| Сюжет / кадр рассказа | 560 × 315 px | 320 × 180 px и 1120 × 630 px |

Основной файл без размерного суффикса; у дополнительных суффикс `-<ширина>w`:

```text
word-23-main.webp              # 320×320
word-23-main-640w.webp         # 640×640

story-seed-01.webp             # 560×315
story-seed-01-320w.webp         # 320×180
story-seed-01-1120w.webp        # 1120×630
```

Так же обработать alternate и context. Не добавлять `?v=…` в имя файла: это параметр URL для обновления кэша.

Текущий принятый набор оптимизирован с качеством WebP 78. Для новых файлов это начальная настройка, после которой обязательно проверить качество на реальном размере: отсутствие заметных артефактов важнее фиксированного значения. Удалить ненужные метаданные. Универсального лимита в килобайтах пока не утверждено; записать фактический вес и проверить загрузку.

## 7. Подключение и приёмка

Ответственный за интеграцию:

1. Сверяет количество, имена, формат, размеры, содержание и единый стиль с заданием пакета.
2. Подготавливает WebP всех необходимых размеров, проверяет фактический вес и качество.
3. Добавляет предметы и связи со словами в [content/illustrations.ts](../content/illustrations.ts). Последовательности связывает со строками нужного текста через `lineIllustrations` в [reading-library.ts](../content/reading-library.ts) или [topic-texts.ts](../content/topic-texts.ts).
4. Обновляет [illustration-sources.ts](../content/illustration-sources.ts): `srcset` и размеры. Указывает корректный `sizes`, включает предварительную загрузку до раскрытия картинки и обновляет версию URL при замене уже опубликованного файла.
5. Проверяет интеграцию в браузере: верный вариант и событие, мобильная и настольная ширина, отсутствие скачков рамки, доступность всех файлов. Для последовательных сцен адаптивную загрузку необходимо подключить отдельно: существующее поле `lineIllustrations` само её не обеспечивает.
6. Проверяет текстовое описание `alt`; в заданиях на называние оно не должно выдавать ответ. Обновляет каталог/учёт пакета и проверки изображений. Проверка существующих 120 файлов не заменяет проверку нового пакета.
