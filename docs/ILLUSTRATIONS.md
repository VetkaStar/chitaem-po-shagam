# Иллюстрации

Подключён пользовательский архив reading-reviewed-120.zip: 40 комплектов по три варианта, 120 файлов. Исходник не изменён. Перед интеграцией сохранена копия кода backups/reading-app-before-illustrations-2026-09-10.zip.

Для сайта сделаны WebP quality 86 без изменения размеров: 13 488 306 байт вместо примерно 275 МБ PNG. Квадратные картинки — 1024×1024, шесть сюжетов — 1600×900. Контрольные суммы: ILLUSTRATION-IMPORT.json.

Каталог content/illustrations.ts экспортирует типы, варианты, wordIllustrations и textIllustrations. Путь относительный для GitHub Pages. Галерея components/illustration-gallery.tsx и её CSS отвечают за стабильную рамку и цикл main → alternate → context → main. Подсказка может сразу включить context. В заданиях на называние alt не выдаёт ответ.

Все 12 карточек получили новые картинки. В словах покрыто 35 названий (34 предмета, плюс кошка использует кота); остальные пока показывают прежние значки. Сон и крот добавлены в банк с фильтрацией по изученным буквам. Шесть сюжетов доступны по кнопке раскрытия у соответствующих рассказов и стихов.

Следующий заказ: NEXT-WORD-ILLUSTRATIONS.md и CSV. Полученные позиции помечены в IMAGE-BRIEF.csv. При добавлении материалов обновить каталог, сверить пути и выполнить tests/illustrations.mjs.
