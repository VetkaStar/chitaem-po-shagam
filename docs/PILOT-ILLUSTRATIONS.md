## Границы смежных изменений

`TextExercise` принадлежит координатору: сохранить скрытую до самостоятельного ответа сцену; раннее раскрытие только после записи явной помощи, включая ошибку записи и переключение текста. В authored сохраняется `controller.illustration -> requestHelp -> save`, а компонент показывает только разрешённую проекцию.

Для `app/globals.css` (правит координатор): прежний замер `.local/program-pilot-plan-20261104/images-geometry.json` показал при 1280x720 лишь 44 из 144 px картинки после открытия. Контейнер `.task-card-body` высотой 212 px имеет scrollHeight 344, картинка видна целиком только после scrollTop=132. Предложение: открытая предметная галерея должна заменять центральный материал/подсказку либо получать отдельную строку `grid-column: 1 / -1` в компактной сетке и размещаться перед второстепенными инструментами. Не уменьшать изображение до полосы и не скрывать переполнение. Проверить живой размер после изменения; один CSS-селектор без замера не считается исправлением.
