# Личная дорожка: предварительное продвижение и возраст

Проверено 2026-11-05. Изменения относятся к Entry08 и личной дорожке. Авторский движок, его ASR-порог, контроль навыков и поставляемые vendor-файлы не менялись.

## Предложение следующего шага

Личная дорожка принимает чтение, проверенное ASR, и явное подтверждение взрослого, который сам слышал чтение всего задания. Подтверждение доступно только на этапе чтения, сохраняется как `verifier: companion` и переживает вопросы по смыслу, паузу и перезагрузку. Подсказка или озвучивание образца сохраняют признак помощи. Нажатие правильного варианта само по себе не доказывает чтение.

Для предложения нужны два правильных самостоятельных чтения разных реальных заданий и разных целей в разных подходах. Задания должны принадлежать эпизодам текущего узла, а сохранённая цель должна совпадать с материалом задания. Не засчитываются помощь, повтор одной цели, один подход, неподтверждённое чтение и придуманные идентификаторы.

`personalNextReadiness` проверяет реальный следующий узел, наличие его эпизодов и заданий, а также явные ограничения букв и функций из актуального `profile.entry08.history.unavailableLetters / unavailableCapabilities`. Проверка выполняется при показе предложения и повторно при нажатии. Выбираются только доступные эпизоды. Если ограничение не позволяет открыть ни один эпизод, видны конкретная причина, продолжение текущего уровня и выход к тренажёрам для подготовки. Сам выход к тренажёрам не снимает ограничение.

Это предварительный переход в учебном режиме. Пустые `knownLetters`, `availableCapabilities`, `skillBasis` нового профиля не означают доказанную недоступность материала и не блокируют личную дорожку навсегда. Формальная готовность к авторским проверкам остаётся отдельной. Дорожка не записывает `confirmedSkills`, `skillBasis`, освоенные узлы или доступные функции. Реальные ограничения не выводятся из возраста и не снимаются по одному прочитанному слову.

По окончании эпизода есть два явных действия: «Попробовать следующий шаг» и «Продолжить на этом уровне». Обычное продолжение больше не принимает предложение автоматически.

## Возраст

В основном профиле отдельно выбираются `12` и `13+`. Старый `12+` продолжает читаться и отображается как требующий уточнения, но не предлагается для новых профилей.

Границы Entry08: 3-7 лет -> `under8`; 8-12 -> `8to12`; `13+` -> `13plus`. Старый `12+` без уточнения -> `unknown`. Если возрастная группа уже была уточнена в Entry08, старое `12+` её не стирает. `EntryUi.profileAge` запоминает последнее применённое значение основного профиля: неизменённый профиль не перезаписывает более позднее уточнение Entry08; явное изменение основного профиля применяется к сохранению.

Новый профиль передаёт возраст через миграцию, где известное текущее значение приоритетнее старой анкеты. Изменённый профиль обновляет сохранённую дорожку через `persistProfileAge` и `CurriculumController.saveEntry08`, с чтением последней ревизии. При ошибке сохранения пользователь видит сообщение; открытие Entry08 повторяет синхронизацию. Прямой записи учебного состояния в БД нет.

Наблюдения, курсор и активная попытка сохраняются. Уже начатый подход сохраняет бюджет. Следующий подход получает 3 экрана для `under8/unknown` и 5 для остальных. Пустой подход обновляется сразу. Общий бюджет знакомства становится 4/6, если уже использованное число ответов позволяет это; потраченные ответы не удаляются. Изменение возраста не перезапускает завершённое знакомство и не меняет трудность автоматически.

Полный typecheck, общий набор тестов и сборку выполняет координирующий чат после объединения параллельных изменений. Эти целевые проверки не проверяют точность распознавания реальной детской речи.
