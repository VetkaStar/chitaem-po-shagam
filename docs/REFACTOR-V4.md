## Изменения

Карточка задания уменьшена с 815 до 345 строк: материал, ввод, речевой индикатор, подсказки и действия вынесены в компоненты с явными типами. Из useLesson выделены обработчики речи, письма, ловли, озвучка, восстановление прогресса и экспорт. В нём остаются состояние, жизненный цикл микрофона и координация переходов; он по-прежнему самый крупный модуль и не считается окончательно завершённой архитектурой.

Типы результата речи связаны с контрактом распознавателя. Отдельный SpeechController учитывает обычное распознавание и проверку микрофона. В выборе части слова вызов необязательного setEnabled защищён: тест микрофона предоставляет только abort.

CSS приведён к читаемому виду. Файлы функций оставлены рядом с функциями, общая основа — globals.css. Правила и порядок импорта не менялись. Учебный материал, алгоритм распознавания и ключи прогресса не переписывались.
