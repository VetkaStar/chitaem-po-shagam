# Грузовой узел

Самостоятельная игра-конструктор в `public/games/sorting-yard/`. Предыдущая игра `public/games/factory/` не изменена. Новая страница доступна по `/games/sorting-yard/index.html` на локальном Vite-сервере; для переноса достаточно целиком скопировать каталог на любой статический HTTP-сервер. Внешних зависимостей и сервисов нет. Через `file://` ES-модули не запускаются.

## Игровая задача

Игрок получает партию разных грузов, несколько складов/резервуаров, пустое поле 10 × 8, препятствия и ограниченный запас деталей. Нужно самому построить линии и настроить сортировку, чтобы вся партия попала по назначению. Девять контрактов разделены на три сложности:

- Старт: два груза, одна развилка, больше запасных деталей. Один контракт требует разделить два твёрдых груза, поэтому одного фильтра по агрегатному состоянию недостаточно.
- Инженер: три груза, последовательное разделение на три адреса.
- Мастер: четыре груза; сначала отделяются жидкости, затем разные жидкости друг от друга, а также разделяются твёрдые грузы. Запас деталей меньше.

Лента перевозит все грузы в упаковке: коробки, канистры, бидоны. Труба перевозит только жидкость. Переход лента → труба включает перелив из тары; отдельного насоса в этой версии нет. Последний блок перед резервуаром обязан быть трубой. Стекло считается твёрдым грузом, несмотря на прозрачность. Нажатие на груз в партии показывает его свойства.

Разветвитель имеет один вход IN сзади основной стрелки. Подходящие правилу грузы уходят в выбранный боковой выход ✓; остальные идут прямо. Фильтр проверяет жидкость/твёрдый груз или конкретный материал. Разветвитель можно поворачивать, боковой выход выбирать справа или слева относительно движения.

## Строительство и запуск

Детали перетаскиваются мышью, пальцем или пером. Для сенсорных устройств также доступно «выбрать деталь → нажать клетку». Установленный блок можно выбрать, перетащить, повернуть, настроить или убрать; удаление возвращает его в запас. Перемещение/замена сохраняет баланс деталей. Кнопка «Отмена» восстанавливает до 60 последних изменений, включая очистку. Блоки разгрузки, складов и препятствий неизменяемы.

Поле прокручивается на узком экране; при перетаскивании возле края работает автоматическая прокрутка. «Всё поле» включает уменьшенный обзор, «Крупнее» возвращает обычный масштаб. Tab/Enter выбирают клетку или действие, стрелки перемещают фокус по полю, R поворачивает выбранную деталь, Delete удаляет выбранную деталь, Escape отменяет перенос/выбор.

Партия выпускается постепенно. Кнопки: запуск, пауза/продолжение, один шаг, скорость 1×/2×/4×, стоп. Во время выполнения и паузы редактирование заблокировано; «Стоп» возвращает к схеме. Ошибка подсвечивает место и объясняет причину; схему можно сразу исправить и повторить партию. Проверяются обрыв, неправильный адрес, твёрдый груз в трубе, встречное движение, вход разветвителя, петля и затор. За ошибку нет штрафа, время не ограничено. Скрытие вкладки ставит запуск на паузу; смена контракта отменяет старую симуляцию.

## Изоляция и данные

`model.js`: контракты, свойства материалов, инвентарь, размещение, чистая пошаговая симуляция. `game.js`: управление, перетаскивание, отображение, хранение. `style.css`: стили только самостоятельной страницы. Начальная схема пустая; эталонные решения в модели используются тестами, интерфейс их не подставляет.

Отдельный ключ `sorting-yard-v1` содержит пройденные контракты и схемы. При восстановлении проверяются размеры поля, типы деталей, направления, фильтры, фиксированные клетки и запас. Повреждённая схема заменяется пустой. При недоступном хранилище игра работает в памяти. Сохранение не связано с профилем ребёнка и не является защищённым серверным учётом достижений.

Игра не подключена к занятиям, наградам, таймеру отдыха, микрофону или учебному прогрессу. Интеграция остаётся отдельной задачей другого разработчика.

## Проверки

- `node tests/sorting-yard.mjs` включён в общий `tests/regression.mjs`: решаемость всех контрактов, точные количества доставок, фильтры, свойства грузов, входы резервуаров, циклы, лимиты, перенос и валидация сохранения.
- `node tests/sorting-yard-browser.mjs`: перетаскивание мышью/касанием, строительство схемы через UI, неверный фильтр и исправление, отмена, клавиатура, шаг/пауза, все девять побед, сохранение, узкие экраны и недоступный localStorage. Playwright берётся из `PLAYWRIGHT_PACKAGE` либо установленного пакета, браузер по умолчанию Edge. Снимки: `.local/sorting-yard-browser/`.
- Основные команды проекта: test, typecheck, build. В среде без npm их содержимое запускается напрямую через Node, без изменения зависимостей.
