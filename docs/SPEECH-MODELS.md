# Локальные модели распознавания — 17.09.2026

В общей панели «Для взрослого» добавлен блок «Распознавание речи». Выбор модели и обработка микрофона сохраняются в настройках текущего локального профиля. По умолчанию остаются Vosk и включённая обработка. Для сравнения выключить «Обработка микрофона»: запрашиваются `noiseSuppression: false`, `autoGainControl: false`, `echoCancellation: false`. Фактически принятые браузером значения видны при проверке. Системную обработку драйвера эта галочка не гарантирует отключить.

## Что подключено

- Один вход `startLocalSpeech`: выбор действует в обычных занятиях, текстах библиотеки и голосовых пробах входа 0.8.1. Vosk сохраняет прежнюю логику уверенности и грамматики.
- Кнопка «Проверить распознавание» в родительской панели: готовность, уровень микрофона, фактические настройки захвата, финальные расшифровки и длительность обработки. Завершение дополучает текущую попытку; отмена/закрытие/фон останавливают микрофон. Расшифровка доступна только взрослому, очищается при закрытии и не пишется в сохранения. Звёзд за проверку нет.
- Голос не отправляется по API. Выбранные веса скачиваются с Hugging Face (Vosk — из прежнего источника), сохраняются в браузерном кэше, пока браузер его не вытеснит. Доступ к сети нужен для первой загрузки; это не добавляет офлайн-установку всего сайта.
- Новые движки исполняются в Web Worker / WASM, один поток без требования cross-origin isolation. Один ONNX worker на приложение; модель переиспользуется между карточками, освобождается при смене ONNX-модели или через минуту простоя. Отмена загрузки прекращает worker. Ошибки не подменяются другой моделью.
- Zipformer обрабатывает поток с endpoint-паузой 0.8 с. GigaAM и Whisper обрабатывают фрагмент после паузы 0.8 с либо каждые 20 с. Передача PCM ограничена очередью 40 с: слишком медленная модель останавливается с сообщением. Короткий звук сохраняется вместе с предысторией; одна тишина не отправляется на непотоковое распознавание.
- GigaAM v3 использует отдельный препроцессор: 16 кГц, окно/FFT 320, шаг 160, 64 HTK mel, `center=false`, log-clamp 1e-9…1e9. Дефолты библиотеки `onnx-asr-web@0.1.3` не подходят v3. CTC/RNNT выбираются явно.

## Граница автоматического зачёта

У новых адаптеров нет откалиброванной уверенности по словам, сопоставимой с Vosk. В обычных занятиях теперь принимается только полное совпадение окончательного результата с ожидаемым словом, слогом или выделенной строкой (регистр и пунктуация не учитываются). Частичная гипотеза, один звук вместо слова, лишние слова и обрывок строки не засчитываются; накопление таких обрывков не включено. Уверенность не подставляется. Вход и личная дорожка получают окончательный текст с неизвестной confidence и проверяют полное совпадение своим движком. Это проверка совпадения текста, не оценка произношения или беглости. Ручное подтверждение остаётся доступным, свободная расшифровка ребёнку не показывается.

Сравнение качества проводить через родительскую проверку на одинаковых слогах/словах, включая Ш/Ж/Щ/Ч/С/З, с обработкой и без неё. Отдельно фиксировать ошибки, задержку, пропуски коротких звуков, первое скачивание и повторный запуск на каждом устройстве. Проверка взрослой записи не заменяет детскую речь.

## Проверки и повторный запуск

`tests/speech-runtime.mjs` включён в общий `test`: каталог, параметры микрофона, сегментация, формат признаков GigaAM, пауза, сброс, завершение, поздние события, закрытие микрофона, отсутствие выдуманной уверенности.

`node tests/speech-settings-browser.mjs`: реальные браузерные настройки захвата и интерфейс 390/820/1920, семь вариантов, сохранение после перезагрузки, отсутствие горизонтального переполнения, остановка при закрытии. Worker в этом тесте имитируется; вычисление моделей проверяется отдельно.

`node tests/speech-models-browser.mjs <model-id> ...`: реальная собранная модель в Edge/WASM. Сначала выполнить `npm run build`. Требует Playwright (путь можно задать `PLAYWRIGHT_PACKAGE`) и локальный `.local/speech-tests/sample.wav`, например [публичный пример модели](https://huggingface.co/csukuangfj/sherpa-onnx-streaming-zipformer-small-ru-vosk-int8-2025-08-16/resolve/main/test_wavs/0.wav). Тест намеренно не входит в обычный `test`: скачивает большие веса, проверяет только запуск и непустую расшифровку. Результаты — `.local/speech-tests/browser-report.json`, профиль/кэш и снимки тоже только в `.local/speech-tests`.

Все шесть новых вариантов запущены в Edge/WASM на публичной взрослой записи. Три варианта GigaAM и Whisper распознали «я тебя люблю», оба Zipformer пропустили «тебя». Это один технический пример, а не рейтинг точности. Реальные старые телефоны, планшеты и детская речь ещё не проверены.

## 18.09.2026 — Совместное распознавание

Кнопка «Быстрая Zipformer INT8 + вторая модель» включает два независимых worker с одним захватом микрофона. Zipformer получает непрерывные копии PCM и отдаёт только предварительную подсветку; даже его финальные результаты не подтверждают чтение. Вторая модель (GigaAM CTC INT8/FP32, RNNT INT8 или Whisper Base INT8) получает тот же звук по границам пауз и единственная вызывает проверку окончательного ответа.

Выбор хранится в speechModel как combined:<id>, проходит общий разбор настроек и действует в занятиях, библиотеке и входе. Кнопка «Одна модель» возвращает обычный режим. Границы сегментов сбрасывают поток Zipformer; поздние предварительные результаты уже проверенных сегментов игнорируются. Пауза инвалидирует обе очереди, уход останавливает общий микрофон и освобождает быстрый worker. Ограничения очереди предотвращают неограниченное накопление аудио.

Проверки: speech-runtime — раздельные роли, единый захват, отмена и поздние результаты; speech-settings-browser — сохранение режима, две модели и один микрофон, экраны 390/820/1920. Полный check пройден. Настоящие Zipformer INT8 и GigaAM CTC INT8 одновременно распознали имеющуюся взрослую запись в Edge/WASM. Это не оценка детской речи или производительности старых устройств.


## 18.09.2026 — Временный порог GigaAM CTC

Для INT8 и FP32 извлекаются реальные выходные логиты CTC. Оценка: softmax по словарю каждого кадра, максимум вероятности внутри каждой группы одинаковых небланковых токенов и минимум по выданным токенам. Пустые ответы, NaN и несовместимая форма не получают выдуманную оценку. Это эвристическая некалиброванная оценка модели, не вероятность правильного чтения ребёнка. Она не зависит от ожидаемого задания.

В проверке взрослого видны оценка и отметка ниже порога. speechConfidenceThreshold сохраняется, 0% выключает дополнительный фильтр. Для CTC результат ниже заданного порога не продвигает чтение в занятиях, библиотеке и входе; отсутствующая оценка при включённом фильтре также не подтверждает ответ. Подтверждённый префикс сохраняется. Пороги Vosk неизменны. Для RNNT, Whisper и Zipformer эта настройка не показывается и не применяется: сопоставимых оценок не подключено.

В совместном режиме окончательное решение остаётся у GigaAM: ошибка Zipformer не является вето. Предварительные результаты не дают зачёт; части ещё должны последовательно покрыть весь целевой материал. Пустой GigaAM пока не заменяется ответом Zipformer. Порог выбирается опытным путём; обе CTC модели проверены на технической взрослой записи, детская речь не проверялась.
