# Карта стилей

Общая основа — app/globals.css: переменные темы, шрифты, каркас занятия, базовые кнопки и диалоги. Файл отформатирован для чтения и поиска. Стили отдельных функций остаются рядом с ними.

| Файл | Область |
| --- | --- |
| features/portal/portal.css | Главная, кабинет, о проекте, шапка |
| features/lesson/practice.css | Переключатели, окошки и игровые элементы |
| features/lesson/vision.css | Палитры и различия без цвета |
| features/lesson/bubble-layout.css | Поле и сетка пузырьков |
| features/lesson/rest-layout.css | Постоянная рамка отдыха и карточки пар |
| features/lesson/reading-guide.css | Подсветка слова/слога и выбор части |
| features/library/text-practice.css | Чтение, письмо и вопросы |
| components/completion-celebration.css | Поздравление после игры |

Порядок подключения сохранён. ReadingApp подключает practice → vision → bubble-layout → rest-layout. Последние два файла уточняют геометрию игр. Остальные подключены соответствующими компонентами или общей основой. Не перемещайте импорты без проверки каскада.

В V4 изменено форматирование, но не селекторы, значения, вложенность и порядок правил. Собранный CSS совпадает со старой версией.
