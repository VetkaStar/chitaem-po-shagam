# Карта стилей

Токены цвета и шрифты — app/theme.css и app/fonts.css. Каркас приложения — app/shell.css. Оба файла подключает app/globals.css. В нём же базовые кнопки, заголовки, общий лист задания для занятия и текстов, окно «Для взрослого» и отдых. Стили отдельных функций лежат рядом с ними.

| Файл | Область |
| --- | --- |
| app/theme.css | Переменные палитр: основная и тетрадная голубая. Атрибуты data-layout, data-look, data-paper на html |
| app/shell.css | Шапка, меню разделов, сетка страницы, масштаб экранов 1080 и 2К |
| features/portal/portal.css | Главная, кабинет, о проекте, знакомство |
| features/portal/style-picker.css | Выбор раскладки, оформления и цвета страницы |
| features/lesson/lesson.css | Весь экран занятия в раскладке «Порядок» |
| features/lesson/focus.css | Раскладка «Фокус»: полоса над заданием, страницы без меню разделов |
| features/lesson/practice.css | Настройки упражнения, пузырьки и пары, колонка контента |
| features/lesson/vision.css | Палитры и различия без цвета |
| features/lesson/bubble-layout.css | Поле и сетка пузырьков |
| features/lesson/rest-layout.css | Рамка отдыха и карточки пар |
| features/lesson/reading-guide.css | Подсветка слова и слога в тексте |
| features/library/text-practice.css | Чтение, письмо и вопросы по текстам |
| components/*.css | Строка тем, меню настроек, заголовок задания, инструкция, автопереход, галерея, поздравление |

## Порядок каскада

static-entry/main.tsx подключает приложение раньше app/globals.css, поэтому globals.css идёт в каскаде последним. ReadingApp подключает practice → vision → bubble-layout → rest-layout → lesson → focus. Стили компонентов подключаются вместе с компонентами.

Чтобы не спорить с общими правилами через !important, правила занятия ограничены .lesson, а правила «Фокуса» — :root[data-layout='focus']. Подсветку букв при включённом режиме для дальтоников рисует vision.css. Поэтому цветные плитки в lesson.css ограничены [data-vision='off'].

!important остаётся только там, где без него не обойтись. Это отключение и остановка движения: спокойный режим, prefers-reduced-motion, статичные и лопнувшие пузырьки, пойманные карточки. Это правила поверх встроенного style: цвета пузырьков в режимах для дальтоников и высота полосок звука. Ещё скрытие динамиков при выключенном звуке и узкие кнопки режимов текстов на телефоне. У диалогов его нет: утилиты Tailwind лежат в каскадном слое и уступают обычным правилам.

Не перемещайте импорты без проверки каскада. После правок стилей сравнивайте вычисленные стили экранов до и после.
