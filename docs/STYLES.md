# Карта стилей

Единственный локальный файл оформления — `app/globals.css`. Его один раз подключает `static-entry/main.tsx`. В компонентах нет CSS-импортов, DOM-атрибутов `style` или записи в `element.style`. Имена классов и `data-*` передают состояние; палитры, размеры и анимации определены в CSS. Prop `style` у `Welcome` — объект выбора раскладки/оформления, а не DOM-оформление.

## Разделы globals.css

Внутри файла сохранены подписанные секции прежних модулей. Они помогают найти нужную область; прежние отдельные CSS-файлы удалены. Шрифтовые файлы и лицензии остаются в `app/fonts`, URL по-прежнему разрешаются относительно `app`.

| Секция | Область |
| --- | --- |
| practice, vision, bubble-layout, rest-layout | Настройки упражнения, доступность, сетки и рамка отдыха |
| auto-advance, style-picker, completion-celebration | Автопереход, выбор оформления, поздравление |
| practice-menu, topic-bar, exercise-header, task-instruction | Меню, тема, заголовок и инструкция |
| reading-guide, text-practice, illustration-gallery | Подсветка чтения, тексты, иллюстрации |
| lesson, focus, notebook | Карточка занятия и две раскладки с тетрадным оформлением |
| fonts, theme, portal, shell | Шрифты, токены, страницы портала и каркас |
| original shared rules | Прежние общие правила globals.css |
| State attributes | Привязки состояний, прежде передававшиеся через inline style |
| Shared UI primitives | Семантические классы общих компонентов в слое utilities |

## Порядок каскада

До переноса порядок проверен по фактическим модулям сборки Vite: practice → vision → bubble-layout → rest-layout → auto-advance → style-picker → completion-celebration → practice-menu → topic-bar → exercise-header → reading-guide → task-instruction → text-practice → illustration-gallery → lesson → focus → notebook → globals. Вложенные локальные импорты globals раскрыты как fonts → theme → portal → shell → прежние общие правила. Порядок локальных правил сохранён.

Пакетные импорты Tailwind и tw-animate-css остаются в начале единственного файла: это требование CSS `@import`. Слои Tailwind сохранены; обычные правила приложения по-прежнему сильнее utility-слоя. Стили общих UI-компонентов используют семантические классы и `@apply` внутри `@layer utilities`. Нельзя переносить их в обычные правила: это изменит приоритет относительно диалогов и каркаса.

Правила занятия ограничены `.lesson`, «Фокуса» — `:root[data-layout='focus']`, «Тетради» — `:root[data-look='notebook']`. Цвет бумаги задают токены. Номер задания берётся из `data-number`. Цветные буквенные плитки обычного режима ограничены `[data-vision='off']`; остальные режимы добавляют различия без цвета.

`!important` сохранён для прежних исключений: спокойного режима, prefers-reduced-motion, остановки/завершения движения, специальных палитр пузырьков, высоты индикатора в спокойном режиме, скрытия динамиков и узких кнопок режимов. Консолидация не пересматривает эти правила.

## Состояния и динамические значения

- `data-vision` определяет CSS-переменные палитры на корне приложения, портальных диалогах и образце. В `lib/vision.ts` остаются идентификаторы, названия и символы; цветовых значений и фабрики inline style там нет.
- `data-interface-scale` на `html` задаёт `--preferred-zoom` для 100/120/140/160%. Прежнее медиаправило применяет масштаб только от 1800×900 CSS-пикселей; на меньшем окне действует 100%, сохранённый выбор не сбрасывается.
- `data-lane`, `data-speed`, `data-paused` сохраняют длительности, задержки и паузу трёх летящих карточек; скорости 0.5/1/1.5/2.
- `data-color`, `data-index`, `data-speed`, `data-columns`, `data-rows` управляют пузырьками; таблица включает все 15 позиций и скорости 0.5/1/2. Сетки пузырьков и пар сохраняют прежние вычисленные размеры.
- `data-letters` задаёт точное число символов материала. Селекторы 0–64 покрывают весь текущий словарь и слоги, включая разделители; регрессия проверяет этот предел. При добавлении более длинного материала таблицу нужно расширить. Пользовательского редактора слов сейчас нет.
- Полоски микрофона — SVG `.equalizer-bar`: значение `height` передаёт точную геометрию `8 + level × 48` без округления. Цвет, ширина, скругление, переход и доступный спокойный режим остаются в CSS. Распознавание и расчёт спектра не изменены.

Типизированный CSS `attr()` не используется: перенос не требует новой поддержки браузером числовых атрибутов в CSS.
