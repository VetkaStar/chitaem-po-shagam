## Завершённая диагностика

- `diagnostic-v2`: 40 случаев,10 с найденным по центру поля скрытым вводом (9 fly и1 words/type), pageerror=[], sampled sourcesChanged=false. Полная видимость картинок/вариантов в этом проходе ещё не входила в автоматический verdict; поэтому его30 PASS не означают приёмку30 режимов.
- `diagnostic-content`: отдельно28 случаев words/read/type, pictures/free/letters и answer букв/слогов/слов, без повторной ловли. **15 с дефектами видимости:8 картинки,1 words/type Порядок1280,6 answer на1280;13 без этих дефектов**, pageerror=[]. Поля/варианты/иллюстрации проверены целиком в границах body до ввода, без scrollIntoView. Главная кнопка нажимается через page.mouse.click в измеренный центр с предварительным hit-test, а не locator.click. Ни одного нового перекрытия основной кнопки в этом проходе не найдено.
- Во время `diagnostic-content` изменился `app/globals.css` (SHA256 до/после различаются; остальные9 наблюдаемых файлов стабильны). Поэтому15 случаев - воспроизведённые диагностические замечания, **не окончательный verdict v4**. Файл CSS этот чат не менял. Времена проходов и SHA256 записаны в report.json.

Уточнённые замеры картинки в content-прогоне: Порядок1280 поле709,19..757,19 при body.bottom546,50; Фокус390 поле559,09..613,09 и окошки585,94..639,94 при body.bottom574. На ПК обрезана также сама иллюстрация; на телефоне картинка видна, ввод ниже неё скрыт. Эти изменения размеров относительно v2 отражают продолжающиеся правки CSS.

Исходное положение фиксируется явно при body.scrollTop=0. Автофокус самого приложения может прокручивать окошки; это не обеспечивает одновременную видимость иллюстрации и ввода. После fill/выбора вариантов Playwright также может прокрутить материал - такой успешный функциональный шаг не отменяет исходный FAIL геометрии.

Вероятная область исправления (по исходникам, без правок): `ExerciseCard.tsx` размещает материал/изображение и input в `.task-card-material` внутри ограниченного `.task-card-body`; `ExerciseMaterial.tsx` выводит3 дорожки либо галерею; `AnswerCard.tsx` размещает варианты после крупного материала. Обычные размеры этих элементов не помещаются в212px body Порядка1280. Конкретное решение остаётся владельцу карточки, без скрытия функций и полей.
