# Разделы, тренажёры и режимы — 16.09.2026

В меню два уровня: раздел и тренажёр. Режимы переключаются внутри выбранного тренажёра и не дублируются в меню или карточках каталога. Повторный выбор открытого тренажёра не сбрасывает его режим. Семь основных разделов сохранены.

| Раздел | Тренажёр | Режимы |
| --- | --- | --- |
| Буквы | Буква | Читаю, Ловлю, Пишу, Отвечаю |
| Слоги | Слог | Читаю, Ловлю, Пишу, Отвечаю |
| Слоги | Состав слога | Собираем, Находим часть |
| Слова | Целое слово | Читаю, Ловлю, Пишу, Отвечаю |
| Слова | Состав слова | Собираем, Находим часть, Делим на части, Меняем |
| Слова | Читаем и понимаем | Читаю, Слушаю, Вместе со взрослым (выбор при запуске) |
| Картинки | Называем предмет | Свободный ответ, Окошки для букв |
| Предложения | Предложение | Читаю, Отвечаю, Пишу |
| Предложения | Состав предложения | Находим часть |
| Рассказы | Рассказ | Читаю, Отвечаю, Пишу |
| Рассказы | Состав текста | Находим часть |
| Стихи | Стихотворение | Читаю, Отвечаю, Пишу |

Названия «Конструктор слов» и самостоятельного тренажёра «Выбираем ответ» в меню не используются. В «Предложение → Отвечаю» сохранены прежние вопросы к тексту; дополнительные вопросы исходного банка выбираются внутри этого режима. На ранних темах, где подходящих новых вопросов нет, прежние задания остаются доступны.

«Отвечаю» предлагает выбор ответа. В «Читаем и понимаем» сначала отдельно фиксируется результат чтения или прохождение этого этапа без оценки, затем раскрываются варианты. Пока это отдельный тренажёр по согласованному решению; тип задания сам по себе не определяет пункт меню.

`features/trainers/navigation.ts` — единый каталог разделов и тренажёров. `TrainerGroup.tsx` объединяет существующие исполнители состава, сохраняя их маршруты и результаты. `AppPortal.tsx` связывает каталог с обычными занятиями. Общий CurriculumController остаётся единственным владельцем прогресса; исходный банк и сохранения не мигрируют и не очищаются.

Показаны только имеющиеся режимы. Два задания сборки предложения доступны официальной программе, но отдельная серия сборки пока не показана, поскольку её исполнитель требует не менее трёх материалов. Новые задания для заполнения меню не выдумываются.

## Как проверять

1. Раскрыть «Слова»: должно быть ровно три пункта — «Целое слово», «Состав слова», «Читаем и понимаем».
2. Открыть «Целое слово» и переключить четыре режима. В меню всё время выделен один тренажёр; повторный клик его названия не сбрасывает режим.
3. В «Составе слова» переключить четыре действия. Начать сборку, открыть другой режим и вернуться: начатое занятие можно продолжить.
4. Проверить остальные разделы по таблице, включая оба режима картинок и прежние вопросы текстов.
5. Повторить на 390×844, 820×1180 и 1920×1080. Подменю не должно двигать верх содержимого на планшете; на телефоне выбор тренажёра закрывает меню.

Проверки: `tests/trainer-menu-browser.mjs`, `tests/answers.mjs`, `tests/answers-browser.mjs`, `tests/instruction-audio-browser.mjs`. Детальная доработка экранов каждого тренажёра продолжается по одному.
