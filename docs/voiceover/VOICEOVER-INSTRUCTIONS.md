# Порядок работы

Сначала подготовить небольшой пилот одним спокойным взрослым голосом: инструкция, слово УХО, звуки У и Щ, слоги ЩА и ЩУ, короткая похвала, рассказ «Росток» и стихотворение «Кот у окна». Пол и тембр голоса ещё не выбраны. До массовой записи согласовать пилот с заказчиком. После выбора держать один голос, произношение, громкость и акустику во всём пакете.

Порядок партий: инструкции и обратная связь; названия букв; звуки и слоги; слова и картинки; тексты с вопросами и ответами; разминки. Для каждого готового файла отметить ID и вариант в реестре. Не добавлять новые фразы и не исправлять учебный текст без отметки: ниже есть отдельный список мест для редакторской проверки.

# Общие требования к чтению

Обращение на «ты», доброжелательно и без сюсюканья. Голос спокойный, с ясными согласными, естественным дыханием и завершёнными фразами. Не шептать, не кричать, не изображать мультяшного персонажа. Похвала тёплая и короткая, без резкого скачка громкости; ошибка или нераспознанный ответ — нейтральная помощь, без упрёка и разочарования.

Версия normal — естественно, но размеренно. Версия slow — отдельная осмысленная запись с чуть более длинными паузами и спокойным темпом, а не механическое растяжение готового файла. Ориентир для инструкций — около 100–120 слов в минуту, для slow — 75–95; это рабочий ориентир, не метроном. В коротких звуках и слогах темп по словам в минуту неприменим.

Ориентиры пауз: между предложениями 0,5–0,8 секунды; в slow — 0,8–1,2 секунды; перед сменой действия — около 0,5 секунды. Между строками стихотворения — короткая смысловая пауза, без рубленого чтения. В разминках оставлять 2–4 секунды на движение там, где это отмечено. Не затягивать отдельные гласные для создания медленной версии.

Вопрос задавать с живой вопросительной интонацией, не выделяя правильный ответ. Все варианты ответа читать одинаково нейтрально. Реплики диалога слегка различать интонацией, но без смены голоса на карикатурный. «Ау!» — зов на расстоянии, без крика; «Ах!» — мягкое удивление. Стихи читать ритмично, не петь. Точки, кавычки, тире диалога и разделители слогов не называть. Enter произносить «Энтер». Ё не заменять на Е.

# Объём и правила повторного использования

В текущем приложении 33 буквы, 97 уникальных слогов самостоятельных заданий, 115 слов, 12 карточек картинок, 11 заданий сборки слова, 42 текста и 4 двигательные разминки. Части слов и фразы игры добавлены ниже отдельно. Одинаковую запись одного назначения повторно не делать: несколько экранов могут ссылаться на один ID. Полный текст и его строки — отдельные версии монтажа: целое должно звучать связно, а каждая строка должна работать отдельно.

У каждого ID есть normal. Для строк, полных текстов и учебных слов нужны также slow. Для названий букв, звуков, слогов, вариантов ответа и коротких реплик достаточно одной естественно неторопливой версии. Новая аудиосистема должна воспроизводить эти файлы без дополнительного замедления браузерным синтезатором.

# Как собрать динамические реплики

| Группа | Схема воспроизведения и источник подстановок |
| --- | --- |
| Успех | «Верно!» + учебное слово или слог + «Получилось!». Короткий вариант: «Верно!» + слово. |
| Помощь | «Здесь» + материал + «Начни с первой буквы»; «Давай вместе» + материал + «Послушай и повтори»; «Сначала найди» + материал + «Потом прочитай». |
| Автоподсказка | «Здесь» + материал + «Попробуй ещё раз»; «Послушай» + материал + «Теперь ты»; «Найди такой же слог» + материал. |
| Выбор | «Да, это» + материал + «Теперь прочитай»; «Посмотри: первая буква» + название буквы. |
| Буква вместо звука | «Ты назвал букву» + название + «А сейчас попробуй произнести её звук, без названия». |
| Картинка | Подтверждение детали: «Да, здесь есть» + деталь + «Ты заметил деталь!» + уточняющий вопрос. Синоним: «Да!» + вариант + «Ещё можно сказать» + основное слово. |
| Картинка с окошками | «Да!» + вариант + «Тоже подходит!» + «В этом задании учимся писать» + основное слово + «Попробуй это слово». |
| Неподходящая картинка | «Давай рассмотрим картинку» + «Здесь» + слово + «Попробуй написать» + слово. Для сходства по форме — фразы про другую картинку из набора fragment. |
| Опечатка | «Почти!» + «Вместо» + название неверной буквы + «Нужна» + название верной + «Исправь выделенную букву». Для пропуска и лишней буквы — соответствующие fragments. Две переставленные буквы произносить двумя названиями, а не выдуманным словом. |
| Текст | «Слово» + номер + подсказка. «Продолжи со слова» + слово из строки + «Прочитанное начало сохранено». Слова внутри строк перечислены в приложении ниже. |
| Темы | «Сейчас» + текущая тема + «Следующая тема» + следующая тема. В разделах 1–4 добавить приглашение нажать на стрелку. |
| Счётчики | «Пройдено заданий» + число + «Теперь можно отдохнуть»; «Найди две одинаковые картинки» + «Найдено» + число + «Из» + число + «Пар». |

# Редакторские проверки до массовой записи

Тексты выше не переписывались автоматически. Сохранены короткие учебные конструкции «Оса у мха», «У мамы ухо», «Мама мыла, мыла». Вопрос «Как зовут маму?» в тексте «Ау, мама!» имеет ответ «Ау»: формулировка может быть понята как вопрос об имени. Перед массовой записью отметить это заказчику, не заменять самостоятельно.

В словаре ЗАМОК — за́мок, потому что текущая иконка изображает здание. РОСА — роса́; ОСЫ — о́сы; НОСЫ — носы́; СОМЫ — сомы́; МАЛЫ — малы́; МАЛА — мала́; МАЛО — ма́ло. Имена Аня, Соня, Миша, Нина, Ира и Тим читать обычно, без изменения имени. Ударения, добавленные в словарь для исполнителя, не являются буквами, которые ребёнок должен читать.

Чистые согласные и йотированные буквы требуют отдельной проверки педагогом или специалистом по произношению. В документе сохранено разделение текущего приложения; это не новая фонетическая методика. Для Щ особенно проверить, что запись не превратилась в Ш, ШЧ или название «ща».

Существующие одобрения «Молодец» перечислены как материал текущей версии. Этот документ не меняет частоту их показа и не добавляет озвучку после каждого успеха. Права на выбранный голос и допустимое использование записей в приложении исполнитель должен подтвердить в условиях передачи.

# Контроль полноты и подключение

Основные источники: lib/learning.ts, content/word-bank.ts, content/reading-library.ts, content/topic-texts.ts, content/word-bridges.ts, lib/session.ts, lib/typo.ts, lib/picture-retry.ts, features/lesson и features/library, components/rest-hub.tsx, components/color-bubbles.tsx. Код и русские строковые литералы сверены при составлении. Временные технические строки, идентификаторы распознавания, пользовательские расшифровки, названия устройств и юридические тексты кабинета не превращены в учебные записи.

Доступность текстов по темам определяется фильтром букв: один текст может появляться в нескольких темах. Записывается один раз по ID, а не по числу тем. Полный набор ниже не означает, что все 42 текста показываются одновременно на одном экране.

| Контроль | Количество |
| --- | --- |
| Уникальных ID | 1201 |
| WAV файлов с учётом normal и slow | 1428 |
| MP3 файлов для тех же вариантов | 1428 |
| Учебных слов | 115 |
| Текстов | 42 |
| Самостоятельных слогов | 97 |
| Дополнительных отличающихся фрагментов | 85 |

Локальная копия документа и реестра: docs/voiceover/. Файл voiceover-manifest.json содержит точные строки, категории и источники; voiceover-manifest.csv — развёрнутые имена каждого WAV и MP3. При новых материалах добавлять записи в тот же реестр, не перенумеровывать уже принятые ID. До подключения проверить соответствие каждого файла его ID и остановку микрофона на время воспроизведения.
