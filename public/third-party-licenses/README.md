# Third-party license texts

This directory contains the original license texts copied from installed npm packages and the font and Vosk license notices. Package names and versions are reflected in the directory names. See the repository's `THIRD-PARTY-NOTICES.md` for attribution, the inventory method, links to upstream sources, and items whose licenses or notices are not yet verified.

The directory is included in the static site build. It does not cover every possible component of remotely loaded speech models or prebuilt WASM; those remain under investigation.
